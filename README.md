# KS0 Ultra Monitor

Matrix-style monitoring dashboard for IceRiver KS0 Ultra miners.

## Features

- Realtime hashrate
- Average hashrate
- Chip temperature
- Fan RPM
- Clock and offset
- Voltage and offset
- Estimated power consumption
- Firmware
- Uptime
- Pool connection
- Accepted/rejected shares
- Online/offline status
- Multiple KS0 Ultra miners

## Default miners

- Ultra1: 192.168.0.175
- Ultra2: 192.168.0.172

## Umbrel

Designed as an Umbrel App for umbrelOS.
